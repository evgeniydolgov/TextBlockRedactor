# Инструкции для агентов

Проект: локальный текстовый редактор на React + TypeScript + Vite + Tiptap OSS.

Перед работой прочитайте:
1. [Процесс](docs/agents/README.md).
2. [Соглашения](docs/agents/conventions.md).
3. [Критерии готовности](docs/agents/acceptance.md).
4. [Текущую спецификацию](openspec/specs/text-editor/spec.md) и относящиеся к задаче изменения в openspec/changes/.

Сохраняйте минимальный объём продукта: текст, абзацы, H1–H3, undo/redo.
Без отдельной задачи не добавляйте backend, сохранение, облако, коллаборацию,
платные расширения, списки или перетаскивание.

Для изменения поведения сначала опишите требования и сценарии в OpenSpec.
Для исправлений в рамках существующей спецификации и небольших правок документации
достаточно краткого плана и релевантных проверок.
Действуйте в рамках запроса пользователя; не запрашивайте повторно уже данное разрешение.

Перед правками проверьте git status. Не перезаписывайте чужие изменения.
Перед завершением проверьте diff и выполните применимые проверки.
Не объявляйте браузерную проверку выполненной по одному HTTP 200.
Не добавляйте node_modules, dist, секреты и журналы в коммиты.
