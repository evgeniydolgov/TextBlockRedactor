# Критерии готовности

Применяйте только проверки, относящиеся к изменению. Неприменимые пункты отмечайте N/A с причиной.

## Для любой задачи

- [ ] Результат соответствует запросу; лишние функции и зависимости не добавлены.
- [ ] Сохранены чужие изменения; diff содержит только относящиеся к задаче файлы.
- [ ] Документы и относительные ссылки актуальны.
- [ ] В отчёте отделены выполненные проверки от непроверенных предположений.

## Для OpenSpec и документации

- [ ] `npm.cmd run spec:validate` проходит.
- [ ] Спецификации описывают текущее поведение, proposals — будущие изменения.
- [ ] Команды инструкции доступны в установленной версии CLI.
- [ ] `git diff --check` не находит ошибок пробелов.

## Для кода и конфигурации приложения

- [ ] `npm.cmd run build` проходит.
- [ ] `npm.cmd run lint` проходит.
- [ ] Проверены изменённые операции и существенные граничные случаи.
- [ ] Для UI проверена отрисовка в браузере и взаимодействие; один HTTP 200 не считается UI-тестом.

## Регрессия редактора при изменениях его поведения

- [ ] Ввод русского текста, удаление Backspace/Delete и Enter работают.
- [ ] Текст переключается в H1/H2/H3 и обратно без потери содержимого.
- [ ] Undo/redo работают для редактирования.
- [ ] Пустой документ остаётся доступным для ввода.
- [ ] Панель доступна с клавиатуры; активный тип блока соответствует позиции курсора.
- [ ] До отдельной задачи о сохранении обновление страницы сбрасывает черновик,
      а интерфейс сообщает, что изменения не сохраняются.
