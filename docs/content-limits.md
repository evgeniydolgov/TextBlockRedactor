# Ограничения содержимого

Три независимых пропса `TextEditor`:

| Пропс | По умолчанию | Что ограничивает |
| --- | --- | --- |
| maxBlockCharacters | 8000 | Сумму длин text-фрагментов одного блока |
| maxNoteCharacters | 50000 | Сумму длин текста всех блоков |
| maxBlocks | 100 | Количество блоков, включая пустые |

Значения страницы находятся в `NOTE_CONTENT_LIMITS` в
[DocumentPage.tsx](../src/pages/document/DocumentPage.tsx). Они передаются и в
подготовку начальной заметки, и в редактор. Для самостоятельного использования:

```tsx
<TextEditor
  initialContent={blocks}
  maxBlockCharacters={8000}
  maxNoteCharacters={50000}
  maxBlocks={100}
  saveDelayMs={1000}
  onChange={saveNote}
/>
```

Допустимы положительные safe integer. Ноль, отрицательные, дробные, NaN, Infinity
и небезопасные числа заменяются default только соответствующего пропса.
Настройки изолированы для каждого экземпляра; UI для их изменения не добавлен.

## Как считаем

Длина — JavaScript `.length` объединённого `content[].text`, то есть единицы UTF-16.
Пробелы учитываются. Границы блоков, ID, props, JSON-экранирование и размер в байтах
не учитываются. `😀`.length равно 2; `e` с комбинируемым акцентом также занимает 2.
Это локальное правило, не предположение о подсчёте на backend.

Корректная surrogate pair не разрывается. Если она не помещается в остаток блока,
она целиком переходит в следующий; если места в заметке/блоках нет — отбрасывается.
При maxBlockCharacters=1 такой emoji не помещается вообще: принимается только
префикс до него. Графемы из нескольких символов не считаются неделимыми.

## Поведение

- Переполнение paragraph/H1/H2/H3 создаёт обычные paragraph сразу за исходным
  блоком. Первый фрагмент сохраняет тип, props и ID; продолжения получают UUID v7.
  Следующий существующий блок не используется для продолжения.
- При вставке принимается максимальный помещающийся префикс с учётом выделения,
  авторазбиения и числа блоков. Текст вне выделения сохраняется. Когда ничего не
  помещается, документ не меняется. Непоместившаяся середина не пропускается.
- При полном текстовом бюджете удаление и замена выделения доступны. При полном
  бюджете блоков Enter отклоняется; текст можно добавлять, пока не нужен новый блок.
- initialContent и заметка из localStorage нормализуются до создания редактора:
  сохраняется префикс в порядке документа, остаток отбрасывается. На точной границе
  текстового бюджета оставшиеся блоки, в том числе пустые, не загружаются.
  Пустая заметка по-прежнему содержит один пустой paragraph.
- Mount не пишет localStorage и не формирует запросы. Старая большая запись может
  оставаться в storage до первого изменения; редактор и preview используют один
  нормализованный снимок с одинаковыми ID. Загруженный отброшенный хвост не входит в undo.
- Изменение пропсов действует на существующий редактор. Снижение обрезает текущий
  документ по правилам загрузки до следующей отрисовки, курсор сопоставляется
  локальными транзакциями. Увеличение не возвращает удалённый текст.
- Авторазбиение входит в операцию ввода для undo/redo. Обрезка при смене настроек
  сама не добавляется в историю; прежняя история сопоставляется через её изменения.
  Операции истории, превышающие актуальные лимиты, отклоняются.

Лимиты применяются в транзакциях, до обновления представления и onUpdate.
Задержка касается только onChange/сохранения. Промежуточные превышения не попадают
в [автосохранение и диагностику запросов](block-api-requests.md).
Снижение лимитов заменяет ожидающий снимок до немедленного сохранения при уходе.

## Ручная проверка

Unit-тесты проверяют нашу логику и адаптеры на заглушках. Эти UI-сценарии агент
не выполнял; для короткой проверки задайте 4/12/3 вместо 8000/50000/100:

- В paragraph и каждом H1–H3 ввести пятый символ: продолжение в paragraph,
  первый ID прежний, курсор после введённого текста. Повторить ввод в середине.
- Вставить несколько абзацев с курсором в середине: сохраняется помещающийся
  префикс вставки и весь старый невыделенный хвост. Повторить с выделением нескольких блоков.
- Заполнить 12 символов: дополнительный ввод не меняет текст; выделить/заменить
  часть и удалить текст. Заполнить 3 блока и проверить Enter и переполнение блока.
- Ввести emoji на границе блока и заметки; проверить отсутствие половинок пары.
- Завершить IME-ввод около границ, затем проверить Backspace, merge, undo/redo.
- Отменить авторазбиение и повторить: текст и ID восстанавливаются вместе.
- Уменьшить пропсы во время ожидания save, сразу скрыть вкладку: storage и
  request-log содержат только обрезанный снимок. Увеличение ничего не восстанавливает.
- Загрузить превышающую лимиты запись: лишнее не отображается, mount не меняет
  storage и не создаёт запросов. После ввода сохраняется допустимая заметка.
