Страница (DocumentPage)
│  загружает заметку, задаёт лимиты и адаптеры изображений/файлов
│
▼
TextEditor.tsx ─────────────────────── собирает панель и область редактирования
├─ toolbar/
│  └─ EditorToolbar.tsx ────────────── кнопки блоков и их активное состояние
│
├─ hooks/
│  └─ useTextEditor.ts ─────────────── создаёт Tiptap, связывает настройки и onChange
│
├─ extensions.ts ───────────────────── подключает все расширения Tiptap
│
├─ blocks/ ─────────────────────────── действия с блоками
│  ├─ types.ts ──────────────────────── общий тип описания кнопки блока
│  ├─ paragraph.ts ──────────────────── кнопка и команда «Текст»
│  ├─ headings.ts ───────────────────── кнопки и команды H1–H3
│  ├─ index.ts ──────────────────────── собирает текстовые кнопки по порядку
│  ├─ getActiveBlock.ts ─────────────── определяет блок под курсором
│  │
│  └─ attachments/ ──────────────────── блоки image и file
│     ├─ FileNode.ts ────────────────── описывает file-блок и его поля
│     ├─ fileNodeView.ts ────────────── управляет загрузкой и скачиванием файла
│     ├─ fileViewElements.ts ────────── создаёт и обновляет интерфейс file-блока
│     ├─ ImageNode.ts ───────────────── описывает image-блок и его поля
│     ├─ imageNodeView.ts ───────────── управляет жизнью блока изображения
│     ├─ imageViewElements.ts ───────── создаёт и обновляет его интерфейс
│     ├─ attachmentCommands.ts ─────── добавление, удаление, запись ID вложений
│     └─ AttachmentKeyboard.ts ─────── Backspace для выделенного image/file
│
├─ model/ ──────────────────────────── наш формат заметки и передача изменений
│  ├─ document.ts ───────────────────── публичные пропсы TextEditor
│  │
│  ├─ note/
│  │  ├─ noteBlock.ts ───────────────── типы paragraph, heading, image, file
│  │  ├─ createEmptyNote.ts ─────────── создаёт пустую заметку
│  │  ├─ validateNote.ts ────────────── проверяет входящую заметку
│  │  ├─ blocksToTiptap.ts ──────────── NoteDocument → документ Tiptap
│  │  └─ tiptapToBlocks.ts ──────────── документ Tiptap → NoteDocument
│  │
│  └─ lifecycle/
│     ├─ editorOptions.ts ───────────── начальное содержимое и обработчик обновлений
│     ├─ createDebouncedChange.ts ───── ждёт паузу ввода перед onChange
│     └─ bindSaveLifecycle.ts ───────── передаёт ожидающее изменение при уходе
│
├─ identity/ ───────────────────────── сохранение идентичности блоков
│  ├─ uniqueIdOptions.ts ────────────── настройка выдачи новых ID
│  ├─ BlockIdentity.ts ──────────────── подключает команды, сохраняющие ID
│  ├─ preserveBlockIds.ts ───────────── сохраняет ID при смене типа блока
│  ├─ splitWithBlockIds.ts ──────────── старый ID первой части, новый — второй
│  └─ NoteHeading.ts ────────────────── превращает # / ## / ### в заголовок
│                                      без потери ID
│
├─ limits/ ─────────────────────────── ограничения содержимого
│  ├─ core/ ─────────────────────────── расчёты без привязки к интерфейсу
│  │  ├─ limits.ts ───────────────────── значения лимитов и их проверка
│  │  ├─ textBudget.ts ──────────────── подсчёт символов и мест для блоков
│  │  ├─ fitInsertion.ts ─────────────── ищет помещающуюся часть ввода
│  │  └─ normalizeNote.ts ───────────── приводит загруженную заметку к лимитам
│  │
│  ├─ input/ ────────────────────────── ввод пользователя
│  │  ├─ inputHandlers.ts ───────────── печать и вставка с учётом лимитов
│  │  └─ pastePrefix.ts ─────────────── допустимая начальная часть вставки
│  │
│  └─ tiptap/ ───────────────────────── применение правил внутри Tiptap
│     ├─ ContentLimits.ts ───────────── подключает проверки к редактору
│     ├─ limitController.ts ─────────── хранит текущие лимиты и принимает решения
│     └─ transactionContent.ts ─────── читает и нормализует транзакции
│
├─ images/ ─────────────────────────── связь с хранилищем изображений
│  ├─ imageStorage.ts ──────────────── контракт upload/resolve и текущий адаптер
│  ├─ createMemoryImageStorage.ts ───── временное хранилище в памяти страницы
│  ├─ imageUpload.ts ───────────────── асинхронная загрузка и её состояния
│  └─ imageResolution.ts ───────────── получение по ID, показ Blob/URL и очистка
│
└─ files/ ──────────────────────────── связь с хранилищем файлов
   ├─ fileStorage.ts ───────────────── контракт upload/resolve и текущий адаптер
   ├─ createMemoryFileStorage.ts ────── временное хранилище Blob в памяти страницы
   ├─ fileUpload.ts ────────────────── асинхронная загрузка и её состояния
   └─ fileDownload.ts ──────────────── получение по ID, скачивание и очистка URL

Выбор файла в file-блоке → fileStorage.upload(File) → ID и имя в заметке
→ сохранение заметки → кнопка «Скачать» → fileStorage.resolve(ID) → скачивание.
