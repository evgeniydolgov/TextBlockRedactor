Здесь src/blocks/sync отвечает за сохранение данных. Папка src/editor/blocks выше
отвечает за типы блоков, команды и интерфейс внутри Tiptap.

Правка в редакторе
       │
       ▼
Пауза saveDelayMs → onChange
       │
       ▼
createPutSyncAutosave
       │
       ├─ createNoteSaveHandler → noteStorage → полный документ в localStorage
       │          └─ preview и requestLogStorage → только диагностика запросов
       │
       └─ если локальная запись успешна → putQueue
                    │
                    ├─ сравнить с подтверждёнными блоками по ID и содержимому
                    ├─ putSyncStorage → записать отметку до отправки
                    └─ putBlock(полный блок)
                              │
                              ├─ успех → сохранить подтверждение и снять отметку
                              │          └─ отправить последнюю версию этого ID,
                              │             если блок снова изменился
                              └─ ошибка/таймаут → остановить PUT этого ID,
                                                  оставить правки локально

Пока PUT ожидает ответа, редактор остаётся доступным для ввода. После перезагрузки
отметка неизвестного исхода блокирует автоматический повтор этого ID до будущей
сверки с сервером. Создание и удаление блоков пока остаются только в preview.

DocumentPage по умолчанию использует демонстрационный адаптер в памяти. Реальному
сервису передают putBlock и доверенный confirmedBlocks; putBlock={null} отключает
очередь. Данные Map демонстрационного адаптера теряются при перезагрузке, а локальный
черновик и сохранённые сведения очереди остаются в localStorage.
