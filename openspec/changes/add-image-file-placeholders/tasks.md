Выполнены локальные команды из задач:

- Модель: validateNote.test.ts и noteConversion.test.ts — 48 тестов прошли.
- Лимиты, diff/build requests, storage и autosave (восемь файлов из раздела 2) — 71 тест прошёл.
- uniqueIdOptions, attachmentCommands, getActiveBlock и blockCommands — 43 теста прошли.
- `npm.cmd test -- src/blocks/requests/tests/createRequestPreview.test.ts` после адаптации типизированного доступа к текстовому fixture — 3 теста прошли.

Итого: 165 тестов в 15 непосредственно затронутых test-файлах. attachmentCommands проверяет настоящую модель транзакций и истории ProseMirror без DOM, браузера и Tiptap Editor; работа клавиатуры и фокуса в UI этим не проверена.

Прочитан diff затронутых файлов. Локальные ссылки proposal/specs в design существуют. Штатная конфигурация type-check включает весь src; отдельный локальный type-check не настроен, полный tsc/build не запускался. Full quality gate и OpenSpec validation не выполнялись.

Браузерные проверки не выполнялись по правилу проекта. Для ручной проверки пользователем:

2. Проверить неактивные внутренние кнопки, отсутствие диалога, выделение оболочки мышью и клавиатурой.
3. Удалить выделенный блок Backspace, выполнить Ctrl+Z и redo; проверить прежние ID и порядок в диагностике. Отдельно отменить два последовательных добавления и убедиться, что соседний ввод текста не отменяется вместе с блоком.
4. Достичь maxBlocks: обе кнопки недоступны; после удаления блока снова доступны. При полном текстовом бюджете и свободном месте пустое вложение добавляется.
5. Дождаться сохранения, перезагрузить страницу: текст и заготовки восстановлены с прежними ID и порядком. Проверить ввод текста и переключение H1–H3.
