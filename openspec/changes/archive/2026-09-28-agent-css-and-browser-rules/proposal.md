# Proposal

## Why

Пользователь хочет читаемый CSS и исключить самостоятельные браузерные проверки
агента из-за расхода токенов. Текущие критерии готовности требуют UI-проверок
без отдельного запроса, а соглашения не фиксируют формат CSS.

## What Changes

- Закрепить в AGENTS.md и conventions.md: каждая CSS-декларация на отдельной
  строке внутри селектора, отступ 2 пробела, закрывающая скобка на отдельной строке.
  Не вставлять пустую строку между каждой парой деклараций; разделять пустой строкой правила.
- Запретить самостоятельный запуск браузерных проверок любым инструментом,
  включая headless, открытие вкладок, скриншоты и браузерные тестовые стенды.
  Выполнять их только по прямому запросу пользователя на такую проверку.
- Обновить процесс, шаблон задач и критерии приёмки: по умолчанию проверять код
  подходящими CLI-командами, а визуальные сценарии оставлять пользователю.
  Не запрашивать браузерную проверку автоматически при каждой задаче.
- Согласовать оставшиеся проверки изменения modularize-text-editor с новым правилом:
  убрать обязательный автоматический браузерный запуск, явно указать непроверенные
  визуальные сценарии и не объявлять их пройденными.

## Capabilities

### New Capabilities

Нет: меняются правила работы агента.

### Modified Capabilities

Нет: поведение text-editor не меняется. Используется skip_specs: true.

## Impact

AGENTS.md, docs/agents/{README,conventions,acceptance,task-template}.md,
design.md и tasks.md активного изменения modularize-text-editor.
Код приложения и существующий CSS в этой задаче не меняются: форматирование
исходников продолжается в рамках рефакторинга. Не добавляются зависимости,
форматтеры, браузерные инструменты и тестовая инфраструктура.
Настройки запуска приложения пользователем остаются прежними.

## Acceptance Criteria

- В документах есть единый пример многострочного CSS без уплотнения деклараций.
- Обычный запрос на реализацию или рефакторинг не означает разрешение на браузерную проверку.
- Без прямого запроса агент не открывает браузер и не запускает браузерные тесты.
- Отчёт различает выполненные CLI-проверки и не выполненные UI-проверки.
- Нет обязательных автоматических браузерных шагов в актуальных инструкциях
  и оставшемся плане modularize-text-editor; исторические отчёты не переписываются.
