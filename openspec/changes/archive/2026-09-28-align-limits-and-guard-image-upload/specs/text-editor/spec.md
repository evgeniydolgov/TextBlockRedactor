# Spec Delta

## MODIFIED Requirements

### Requirement: Image upload lifecycle
Кнопка пустого image-блока SHALL открывать системный выбор изображения и передавать выбранный файл в `upload`. Успешный результат SHALL обновлять только исходный пустой image-блок с тем же ID одной отменяемой операцией: записывать результат `id` в `props.url`, результат `name` в `props.name` и сохранять прежний `props.caption`. Поздний результат SHALL NOT изменять другой, удалённый или уже заполненный блок.

#### Scenario: Successful upload
- **WHEN** пользователь выбирает изображение и `upload` успешно возвращает ID и имя, пока исходный image-блок существует и остаётся пустым
- **THEN** на время запроса блок показывает «Загрузка…» и не допускает повторный выбор
- **AND** после успеха тот же блок получает возвращённые `url` и `name`, не меняя ID, положение и caption
- **AND** обновлённый документ проходит через обычный onChange и сохранение

#### Scenario: Upload fails
- **WHEN** `upload` завершается ошибкой
- **THEN** `url`, `name` и caption блока не изменяются
- **AND** блок показывает локальную ошибку и снова позволяет выбрать файл
- **AND** ошибка и состояние загрузки не передаются в onChange и не сохраняются

#### Scenario: Undo and redo uploaded reference
- **WHEN** успешная загрузка записала ID и имя в ранее пустой image-блок, после чего пользователь выполняет undo и redo
- **THEN** undo возвращает этот блок с прежним ID к пустым `url` и `name`
- **AND** redo восстанавливает полученные ID и имя без повторного вызова `upload`
- **AND** ни undo, ни удаление блока не запрашивают удаление файла из хранилища

#### Scenario: Late result after block replacement or removal
- **WHEN** исходный image-блок удалён либо его место занял другой image-блок до завершения `upload`
- **THEN** поздний результат не меняет заметку, другой блок, историю или цикл onChange
- **AND** удалённый блок не восстанавливается автоматически

#### Scenario: Late result after block is populated
- **WHEN** исходный image-блок с тем же ID получил непустой `props.url` до завершения прежней загрузки
- **THEN** поздний результат не перезаписывает его `url`, `name` и `caption` и не создаёт новую операцию истории или onChange
