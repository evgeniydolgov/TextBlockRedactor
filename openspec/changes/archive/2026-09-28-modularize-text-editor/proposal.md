# Proposal

## Why

TextEditor.tsx объединяет создание Tiptap, начальный документ, определение активного
блока и разметку панели. Несмотря на небольшой размер (63 строки), разделение этих
обязанностей позволит расширять редактор без накопления всей логики в одном компоненте.

## What Changes

- Сохранить TextEditor.tsx как точку сборки редактора и его публичный интерфейс
  initialContent/onChange; вынести инициализацию в хук, панель в отдельный компонент.
- Инкапсулировать «Текст» и H1–H3 в типизированных описаниях блоков: подписи,
  команды применения и определение активности. Заголовки описывать одной реализацией
  с тремя вариантами уровня; панель подключает общий упорядоченный набор блоков.
- Отделить страницу документа и её стили от глобальной оболочки приложения.
- Разложить CSS по ответственности и сделать форматирование читаемым.
- Удалить неиспользуемые остатки шаблона Vite после проверки ссылок на них.
- Обновить карту проекта и соглашения: ориентир для исходных файлов — 100–150 строк,
  меньшие файлы допустимы; не сокращать число строк уплотнением кода.

## Capabilities

### New Capabilities

Нет: это внутренний рефакторинг без новых функций.

### Modified Capabilities

Нет: требования text-editor и его JSON-контракт сохраняются.
Установлено skip_specs: true; delta-спецификация не создаётся.

## Impact

Затрагиваются src/App.tsx, страница документа, src/editor/, CSS,
неиспользуемые src/App.css и src/assets/, README.md и docs/agents/conventions.md.
main.tsx остаётся точкой запуска React, TextEditor — точкой композиции редактора.
Новые runtime-зависимости не нужны.

Вне границ: новые типы блоков, сохранение, backend, облако, коллаборация,
перетаскивание, меню команд, изменения дизайна и поведения, отдельные экземпляры
Tiptap или React NodeView для каждого абзаца/заголовка, универсальная система плагинов.
Коммиты и индекс Git остаются под управлением пользователя.
