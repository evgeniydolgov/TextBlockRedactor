# Proposal

## Why

Идентификаторы блоков сейчас создаются несколькими путями: crypto.randomUUID в нашей модели и стандартный генератор UniqueID. Нужно единое правило: все новые ID сущностей заметки генерируются как UUID v7, а переданные существующие ID сохраняются.

## What Changes

- Ввести общий генератор UUID v7 и подключить его к UniqueID, фабрике пустой заметки и адаптеру splitBlock.
- Не проверять версию UUID у входных и выходных ID: UUID v4 и произвольные непустые уникальные строки принимаются и сохраняются без замены. Текущие проверки непустой строки и дубликатов остаются.
- Сохранить правило: первый фрагмент при split удерживает старый ID, второй получает новый UUID v7.
- Добавить прямую зависимость uuid и unit-тесты наших точек генерации, проверки входа и сохранения ID; обновить fixtures и примеры.
- UniqueID остается расширением управления жизненным циклом ID; меняется его generateID. UUID v7 — формат, а не замена механизмам обработки paste/дубликатов/истории.
- «Все ID» относится к идентификаторам сущностей данных; технические ключи типов paragraph/h1/h2/h3, имена расширений и DOM-якорь editor-hint не являются ID сущностей заметки. Новые сущности и ID заметки, которых сейчас нет, не добавляются.
- Вне задачи: миграция хранилища, сортировка блоков по ID, новый интерфейс, браузерные проверки и реализация алгоритма UUID вручную.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `text-editor`: единый UUID v7 для генерации новых идентификаторов блоков при сохранении совместимости существующего входа.

## Impact

- Новый общий модуль идентификаторов; extensions.ts, createEmptyNote.ts, splitWithBlockIds.ts. validateNote не меняется.
- package.json/package-lock.json: uuid уже присутствует транзитивно в версии 14.0.2 (MIT), требуется прямая зависимость.
- Unit-тесты, fixtures, coverage.include, docs/note-blocks.md и проектные соглашения об ID.
- Изменение опирается на выполненный, но не архивированный blocknote-compatible-note-model. Его артефакты не переписываются; новый delta добавляет самостоятельное требование формата ID к text-editor.
