# Proposal

## Why

Сейчас API заметки передает внутренний JSON Tiptap. Нужен самостоятельный блочный формат, совместимый со структурой BlockNote для текущих типов блоков, чтобы дальнейшее расширение заметки не связывалось с внутренним представлением редактора.

## What Changes

- **BREAKING**: `initialContent` и `onChange` переходят с Tiptap JSON на массив блоков заметки; пользователь подтвердил этот переход.
- Реализовать формат BlockNote: `id`, `type`, `props`, `content`, `children`. Поддержать только paragraph и heading с level 1–3, обычный текст, стандартные свойства и пустой children.
- Сохранять уникальные ID при редактировании существующих блоков; новые блоки получают новые ID.
- Добавить преобразования между блочной моделью и внутренним документом единственного Tiptap Editor.
- Подключить вывод актуального массива в консоль при изменении документа на странице заметки; без сохранения и дополнительного интерфейса.
- Покрыть новые собственные функции unit-тестами Vitest, обновить существующие тесты API.
- Вне задачи: остальные блоки BlockNote, вложенность, форматирование, ссылки, изменение цветов/выравнивания, drag-and-drop, замена Tiptap на BlockNote, сохранение, backend и облако; без UI/скриншотных тестов.

## Capabilities

### New Capabilities

Нет: расширяется существующая спецификация редактора.

### Modified Capabilities

- `text-editor`: блочный API заметки, формат поддерживаемого подмножества BlockNote, жизненный цикл ID и консольный вывод.

## Impact

- `src/editor/model/`: типы заметки, преобразования, проверка входа, фабрика начального документа, опции редактора и unit-тесты.
- `src/editor/extensions.ts` и адаптеры команд: хранение ID на узлах paragraph/heading и их сохранение при переключении типа.
- `src/pages/document/`: обработчик вывода JSON в консоль.
- Одна новая OSS-зависимость `@tiptap/extension-unique-id`, совместимая с установленным Tiptap; пакеты BlockNote не требуются.
- README, контекст OpenSpec и применимые документы обновляются под новый API; список модулей coverage расширяется.
- Сохраненных данных пока нет, миграция хранилища не нужна. Старый Tiptap JSON на публичном входе больше не поддерживается.
- Источники: [структура BlockNote](https://www.blocknotejs.org/docs/foundations/document-structure), [props](https://www.blocknotejs.org/docs/features/blocks), [paragraph/heading](https://www.blocknotejs.org/docs/features/blocks/typography).
