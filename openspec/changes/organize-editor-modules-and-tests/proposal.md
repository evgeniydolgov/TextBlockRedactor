# Proposal

## Why

Логика редактора, ограничения и тесты сейчас лежат вперемешку, поэтому назначение файлов трудно увидеть по структуре каталогов. `AttachmentNode.ts` объединяет несколько независимых обязанностей и превышает ориентир по размеру; разделение сделает последующие изменения безопаснее и понятнее без изменения работы редактора.

## What Changes

- Разделить `AttachmentNode.ts` по обязанностям: file-узел, image-узел, представление изображения с его обновлением и клавиатурный обработчик.
- Сгруппировать формат и преобразования заметки отдельно от обработки `onChange` и сохранения в `src/editor/model`; в `src/editor/limits` отделить расчёт лимитов от ввода и интеграции с транзакциями Tiptap.
- Перенести unit-тесты в локальные каталоги `tests` рядом с группами модулей, сохранив общие fixtures в понятном месте; обновить импорты и адресные команды тестов в затронутой документации активных изменений.
- Проверить физическую длину TS/TSX/CSS-файлов редактора и прямо связанных модулей; делить файлы длиннее 150 строк по ответственности, если это улучшает ясность, иначе записать причину исключения. Закрепить мягкий ориентир 100–150 строк и принцип группировки по ответственности в `docs/agents/conventions.md`.
- Не дублировать незавершённые задачи `modularize-text-editor`: его пункт 3.1 уже включает правило о размере файлов; при реализации нового change синхронизировать соответствующий пункт старого плана без повторной работы.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Это рефакторинг без изменения требований к поведению; поэтому в `.openspec.yaml` указан `skip_specs: true` и delta specs не создаются.

## Impact

Затрагиваются внутренние файлы `src/editor/`, связанные тесты и их локальные fixtures, адресные пути в документации активных изменений и `docs/agents/conventions.md`. Публичный API `TextEditor`, формат `NoteDocument`, ключи и значения localStorage, лимиты, загрузка и показ изображений, порядок блоков, выделение, Backspace и undo/redo остаются прежними. Новых зависимостей, функций продукта и миграции данных нет.
